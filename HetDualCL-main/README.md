# HetDualCL
This repo is for source code of Neural Networks 2026 paper "HetDualCL: Dual-encoder contrastive learning for heterogeneous graphs". Paper Link: https://doi.org/10.1016/j.neunet.2026.109205

## Requirements
> python==3.7.16\
> torch==1.12.0+cu116\
> torch-geometric==2.2.0\
> torchvision==0.13.0+cu116\
> numpy==1.21.6\
> scikit_learn==0.24.2\
> dgl==0.9.1+cu116

GPU: GeForce RTX 3060 12GB \
CPU: 13th Gen Intel(R) Core(TM) i5-13400F (2.50 GHz)

## Dataset

The datasets used in this work are available for download at:

> Quark Cloud: https://pan.quark.cn/s/49f150f04c35

File: `data.zip` (~5.1 GB). After downloading, unzip it into the `data/` directory at the project root.
